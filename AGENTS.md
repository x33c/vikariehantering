# Release notes

When a change affects substitute-facing behavior, update
`public/vikarie-uppdateringar.json` in the same commit. This file supplies the
administrator's "Meddelande om uppdateringar" draft; it is not generated from Git.
Use the release date and concise Swedish descriptions of verified behavior.
Distinguish in-app notifications from device push. Do not announce unfinished
features or send the announcement automatically. Keep admin-only changes out.
